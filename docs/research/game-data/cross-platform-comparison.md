# Structured-data cross-platform comparison

GOF2 PC, Android, iOS and macOS share the principal database basenames and use index-based relationships. Mobile corpora contain extra dock, wanted-target, weapon-position and collision tables. PC and Android contain eleven standalone language tables; the supplied iOS/macOS extraction does not, so absence is an extraction observation rather than proof that those products lack localization resources.

GOF3D iOS is materially different: its seventeen structured resources are delimited text rather than the GOF2 binary-table set. They may explain older Abyss Engine concepts, but no GOF3D field or delimiter rule is applied to a GOF2 profile.

Confirmed commonality is currently limited to names, repeated high-level entities and observed index references. Binary record layouts are not declared cross-platform compatible until each platform reconstructs unchanged and field values correlate with runtime behavior.
