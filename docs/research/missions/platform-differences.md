# Mission platform differences

DeepOpen represents the older/J2ME campaign with 46 named numeric stages in its reconstruction. GOF2HD native behavior uses a larger range and DLC/version-specific stage repairs. This alone prevents treating one platform's numeric stage meanings as universal.

The PC runtime mod API demonstrates hook-based extension, while no equivalent data-only path is established on Android, iOS or macOS. GOF3D has no mission candidate in the supplied corpus and remains isolated from GOF2 assumptions.
