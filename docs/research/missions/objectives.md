# Mission objectives

DeepOpen identifies an `Objective` runtime class with integer type plus two indices and constructors tied to a live `Level`. Its `achieved(time)` behavior examines live entities and counters. GOF2HD level creation similarly establishes mission-specific runtime behavior.

Objective integers and their full semantics are not yet sufficiently corroborated for a writer. The Workshop will expose them only if a real serialized representation is discovered and independently validated.
