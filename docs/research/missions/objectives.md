# Mission objectives

DeepOpen identifies an `Objective` runtime class with integer type plus two indices and constructors tied to a live `Level`. Its `achieved(time)` behavior examines live entities and counters. GOF2HD level creation similarly establishes mission-specific runtime behavior.

The read-only Objective Explorer catalogs the observed evaluator selectors 0 through 25. Twenty
conditions are corroborated strongly enough to label confirmed, types 6, 13 and 14 remain strong
interpretations, types 9 and 10 are hypotheses, and type 24 remains unresolved. Parameters are shown
as evaluator inputs rather than presumed serialized fields.

Objective integers and their full semantics are not sufficiently corroborated for a writer. No
standalone objective table was discovered, so the Workshop exposes this catalog only as runtime
evidence. A future writer remains gated on a real serialized representation and independent
validation.
